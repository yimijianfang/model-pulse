# ModelPulse 专业基准测试与监控设计

## 目标

将 ModelPulse 从单次模型测速工具升级为面向开发者的本地 API 性能监控工具。产品需要给出可复现、可解释的性能数据，同时保持凭据和测试记录仅存储在本机。

## 产品边界

- 支持快速测试、标准基准和定时监控。
- 增加样本聚合、输出有效性检查、稳定性评价和结构化故障分类。
- 增强概览、历史诊断、告警与数据导出。
- 不加入团队协作、账号系统、云同步、远程控制或权限管理。
- 不默认保存完整模型输出。

## 基准测试模型

### 快速测试

每个模型执行一次请求，用于连接验证和粗略性能判断。结果展示首字延迟、生成阶段吞吐、字符吞吐、端到端有效吞吐和总耗时。

### 标准基准

每个模型默认执行一次预热和三次正式采样。预热不计入统计。多个模型按轮次交错执行，每轮随机排序，降低固定顺序与短时网络变化造成的偏差。

聚合结果提供：

- P50 与 P95 首字延迟。
- P50 与 P95 生成阶段吞吐。
- 字符每秒，用于辅助比较使用不同 tokenizer 的模型。
- 端到端有效吞吐，兼容现有口径。
- 成功样本数、有效样本数与总样本数。
- 波动系数和稳定性等级。

### 定时监控

每个模型每轮仍只执行一次请求，避免隐性增加 API 成本。监控状态由最近有效样本的滚动窗口产生：至少三个有效样本后参与稳定排名，默认使用最近五个有效样本的中位数。性能下降或排名反转需要连续两轮达到阈值后才告警。

## 指标口径

- `ttftMs`：请求开始到第一个非空文本增量。
- `generationMs`：第一个非空文本增量到完成事件。
- `generationTokensPerSecond`：输出 token 数除以生成阶段耗时。
- `charactersPerSecond`：Unicode 字符数除以生成阶段耗时。
- `effectiveTokensPerSecond`：输出 token 数除以请求总耗时，保留现有指标。
- `usageSource`：`provider` 或 `estimated`。
- `validation`：`valid`、`invalid` 或 `unchecked`。

供应商未返回 token 用量时仍可显示估算结果，但估算样本不参与专业 token 排名。字符吞吐可以作为辅助指标。

## 输出有效性

内置的 1–120 基准任务检查数字完整、顺序正确且无额外内容。无效输出保存为样本并标记 `invalid_output`，但不参与聚合排名。

自定义提示词默认标记为 `unchecked`。界面明确提示其无法与经过校验的内置基准混排；后续可扩展自定义验证规则，但不作为本期范围。

## 运行与数据结构

每次用户动作或定时执行生成一个运行批次，批次包含模式、基准配置版本、开始与完成时间。每个实际 API 请求保存为独立样本，并关联批次、轮次和是否预热。

旧 `results` 数据继续保留。数据库通过版本化迁移补充运行批次和新字段；旧记录缺失的新指标显示为不可用。升级后重新建立排名基线，避免新旧统计口径混排。

## 监控体验

概览页优先展示健康模型数、最近一轮成功率、P50 首字延迟、P50 生成吞吐、24 小时异常数和下次执行时间。

模型状态分为正常、性能下降、不可用和数据不足。模型行展示滚动中位数、与上一个窗口的变化、成功率、稳定性和最近测试时间，并提供快速测试与标准基准入口。

历史页支持原始样本与滚动统计切换，按模型、指标、运行模式、状态和错误类型筛选，并查看单次请求的安全元数据。支持 CSV 和 JSON 导出。

## 告警

- 可用性告警：认证、限流、超时、连接和协议故障。
- 性能告警：TTFT 或吞吐相对滚动基线显著恶化。
- 排名告警：相同基准配置下的稳定排名变化。

告警包含模型、指标、当前值、基线值、变化幅度和连续次数。

## 故障分类

稳定错误代码包括 `authentication`、`rate_limit`、`timeout`、`connection`、`protocol`、`invalid_output`、`cancelled` 和 `unknown`。界面显示本地化说明，数据库和导出使用稳定代码。

## 安全与隐私

- 延续 Electron 主进程发起模型请求的架构。
- 渲染进程不接触 API 密钥。
- 不默认保存完整输出内容。
- 错误消息不包含上游响应正文、请求头或密钥。
- 导出结果不包含凭据和自定义请求头。

## 验收标准

- 三种协议均记录新指标并保持现有流式兼容性。
- 标准基准包含一次预热和三次正式采样，且多模型顺序交错。
- 定时监控仍为每模型每轮一次请求。
- 无效输出、估算 token 与不同基准配置不会进入专业排名。
- 旧数据库升级后模型、凭据和历史不丢失。
- 中断、休眠、超时和取消不会生成虚假成功结果。
- 自动化测试覆盖指标、验证、聚合、迁移和告警边界。
